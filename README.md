# CampusCare

CampusCare is a campus service reporting and complaint-tracking app for Dhaanish I Tech College.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. From this directory, run `node server.js`.
3. Open <http://127.0.0.1:3000>.

The server uses only Node.js built-in modules. Runtime complaint and rating data is stored in `data/` and is excluded from Git.
